# stripsvg

Strip encode/decode helpers for svg payloads in pipelines.

**Site:** https://theworker02.github.io/stripsvg/

## Install / run

```bash
git clone https://github.com/theworker02/stripsvg.git
cd stripsvg
node src/cli.js
node --test
```
